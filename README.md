# 🩺 Dr. Gimus — Cuidado próximo, saúde por inteiro

Landing page do **Dr. Gimus**, médico generalista em **Aracaju, Sergipe — CRM-SE 9295**.

Uma experiência com tons de azul-petróleo, navegação fluida e conteúdo pensado para apresentar o profissional e facilitar o contato pelo WhatsApp.

---

## ✨ O que você encontra por aqui

- **Apresentação do profissional** com retrato em destaque.
- **Áreas de cuidado**: consulta clínica, prevenção e acompanhamento.
- **Motivos para buscar uma consulta**, etapas do atendimento e orientações de preparação.
- **Checklist interativo** para organizar a visita.
- **Perguntas frequentes** com respostas expansíveis.
- **Botões de WhatsApp** para conversar sobre agendamento.

## 🎨 Uma experiência com movimento

Entradas suaves durante a rolagem, cartões com destaque ao passar o cursor, brilho que acompanha o mouse e abertura animada das perguntas frequentes.

A página também inclui uma barra de progresso de leitura e atalhos flutuantes para navegar, agendar e voltar ao início. Os efeitos respeitam a preferência de **movimento reduzido** configurada no dispositivo.

## 🛠️ Tecnologias

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Conteúdo e estrutura da página |
| CSS3 | Layout responsivo, cores e transições |
| JavaScript | Interações, checklist e animações |
| Google Fonts | Fontes DM Sans e Manrope |

**Sem framework, instalação de dependências ou etapa de compilação.**

## 💡 Sobre as funcionalidades

- Os botões abrem o WhatsApp; **não confirmam nem registram uma consulta automaticamente**.
- O checklist funciona apenas na página aberta e é reiniciado ao recarregar.
- O projeto não possui formulário de prontuário, banco de dados ou área de login.
- Endereço completo, valores, convênios e disponibilidade são direcionados para confirmação pelo atendimento.
